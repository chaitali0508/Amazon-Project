# 🛒 Amazon Project

A frontend practice project created while learning HTML and CSS. The project is inspired by the visual structure of an e-commerce website and was built to practice creating layouts and styling web pages from scratch.

## ✨ Features

* 🛒 E-commerce inspired user interface
* 📱 Structured webpage layout
* 🎨 Custom styling using CSS
* 🔘 Interactive-looking buttons and UI elements for visual presentation
* 📦 Product-focused sections

## 🛠️ Technologies Used

* HTML
* CSS

## 🎯 Project Purpose

I created this project while learning the fundamentals of HTML and CSS.

The main focus was on understanding how to structure a webpage with HTML and style different elements using CSS without using any CSS framework.

## 📚 What I Practiced

* HTML page structure
* CSS styling
* Layout creation
* Spacing and positioning
* Working with images and content
* Creating reusable visual patterns with CSS
* Building a webpage without using Bootstrap or other CSS frameworks

## 📝 Note

This is a frontend-only practice project. The buttons and other interface elements are included for visual presentation and are not connected to backend functionality.
